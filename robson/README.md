# Robson Motta — portfólio

Projeto independente publicado pelo Render a partir da branch `robson-portfolio`. O serviço de Cida continua usando a branch `main`.

## Publicação
Static Site; build `node robson/build.mjs`; saída `robson/dist`; `SKIP_INSTALL_DEPS=true`. O domínio é fornecido automaticamente por `RENDER_EXTERNAL_URL`.

HTML, CSS e JavaScript ficam em `robson/site`. A construção baixa as fotografias institucionais do Retiro e as fontes, servindo todos os recursos localmente pelo Render. Nenhum anexo privado, currículo ou foto enviados pela usuária está incluído neste repositório.

## Conteúdo desta primeira versão
A atuação e o e-mail profissional foram conferidos no site do Retiro dos Artistas. A criação da Rede Cultura Social está registrada no RJ1/Globoplay e no Museu da Pessoa. Não foram adicionados cargos, datas, formação, estatísticas ou depoimentos sem fonte.

O currículo anexado e as fotografias enviadas na conversa ainda precisam ser incorporados quando estiverem acessíveis. As fotografias atualmente usadas vêm do acervo público do Retiro, com crédito na página.
